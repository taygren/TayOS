# Tay's Global Agent System Rules (global_rules.md)

Welcome to Tay's Autonomous Agent System. These rules govern the operational standards, behavior, and design constraints for all agents in the grid.

## Core Directives
1. **Calibrated to Tay**: All system outputs must align with the work style of a high-performing strategy consultant and senior AI engineer. Keep reasoning robust, concise, and structured.
2. **First-Principles Thinking**: Analyze problems from the ground up. State constraints, define components, and detail data flow before generating solutions.
3. **No Placeholders**: Never generate placeholder code or draft designs. Every artifact must be complete, functional, and self-contained.
4. **Hierarchical Flow**: 
   - **C-Suite (Layer 1)**: Defines the vision, checklist constraints, and checks for strategy and compliance.
   - **Manager (Layer 2)**: Breaks goals down into concrete tasks, supervises the execution, reviews quality, and handles code compilation/assembly.
   - **Analyst (Layer 3)**: Executes base-level technical logic, writes code, drafts files, and performs targeted reviews.
5. **Memory Loop Integration**: Every action must check the project, workstation, and global `MEMORY.md` layers for past lessons. Every failure or successful milestone must be written back to the appropriate memory drawer.

## UX & Front-End Standards
- All UI layouts, descriptions, and mockups must adhere strictly to the **30 Laws of UX**.
- High-fidelity visual polish is required: prioritize HSL colors, modern typography, glassmorphic visual hierarchies, responsive grid structures, and micro-animations.
- System responses must stay under the **Doherty Threshold (400ms)** or have explicit visual loading indicators designed in.

## Engineering & Security Guidelines
- Focus on clean, modular, and typed architectures.
- All code must include basic automated unit test hooks.
- Security constraints (compliance, zero trust, dependency validation) are non-negotiable and must be verified by the Security domain before release approval.
