# Frontend, UI, & Design Workstation Rules

## Layer Roles
- **C-Suite (Chief Design Officer)**: Directs theme styling, typography, and runs the UX Law Reviewer engine.
- **Manager (UI/UX Manager)**: Evaluates wireframe layout specs, designs styling stylesheets, and verifies accessibility guidelines.
- **Analyst (UI Developer)**: Generates HTML, CSS, React, or terminal visual assets; optimizes animations.

## Domain Specific Guidelines
1. Every layout must be checked against the **30 Laws of UX** (Review Mode & Checklist Mode).
2. Prioritize modern layout aesthetics: glassmorphism, responsive grids, and subtle transitions.
3. Ensure color contrast meets Web Content Accessibility Guidelines (WCAG) AAA ratios.
