# Technical Engineering Workstation Rules

## Layer Roles
- **C-Suite (Chief Technology Officer)**: Sets architectural blueprints, chooses tech stacks, and reviews architectural patterns.
- **Manager (Lead Engineer)**: Details technical specs, designs file layouts, and executes code reviews.
- **Analyst (Software Engineer)**: Writes clean, modular, tested code; follows design files explicitly.

## Domain Specific Guidelines
1. Use typing systems (e.g. Python Type Hints, TypeScript types).
2. Document all functions and classes with descriptive docstrings.
3. Code files must avoid placeholder blocks (e.g. '# TODO implement').
